# 使用指引

安装、更新和常用操作见 [README](../README.md)。

1. 下载并解压发布页的安装包，在 Edge 扩展管理页加载包含 `manifest.json` 的目录（使用仓库源码时选择 `extension`）；更新后重新加载扩展并刷新既有网页。
2. 正常播放音视频。「所有网页默认启用」已开启，播放时自动生效。导航和刷新后仍自动管理。
3. 全新安装默认 100%，已有音量设置继续保留；快捷档位 30/70/100/150/200%，完整范围 0–500%。靠近档位轻微吸附；121% 等数值可以选择，方向键逐点调整。
4. 开启自动响度均衡，让内容强弱持续收敛。峰值限制会影响高增益时的实际增幅。
5. 网页列表支持静音、独立音量、跟随统一、停止及恢复。停止后由网页继续控制声音，音量可能变化或变大；若声音未正常恢复，请刷新网页后重新播放。

处理可用时会自动限制过高峰值，旧版保存的上限继续沿用。主面板已移除上限设置；面板右上角「关于」提供保护范围、隐私说明、上游来源和完整许可。

部分跨域媒体、受版权保护的内容或站点限制会影响处理，面板会显示可用状态。Bilibili 播放后点击工具栏扩展图标，面板自动接管；无需关闭自动模式，也不用额外切换开关。手动入口始终位于「网页声音」上方的「当前网页 · 整页接管」卡片，按钮为「接管当前网页声音」；运行时显示「停止整页接管」。未生效或失败会直接显示在网页行。

关闭自动模式不会停止已开启的整页接管，请另用「停止整页」或「停止全部接管」。

当前版本为 [1.1.2](https://github.com/UFOAlastor/volume-balancer/releases/tag/v1.1.2)，已在 GitHub 发布。更新时保留原安装目录以沿用设置。逐页控制在扩展重载/更新或浏览器重启后重置。迁移时先记录设置并停用旧安装，避免两套扩展同时处理同一网页。
