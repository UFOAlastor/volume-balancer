# 兼容性说明

适用于 Microsoft Edge 116+，项目内有 Edge 156 的验证记录；未实际验证其他浏览器，不承诺全面兼容。

- 自动模式用于 HTTP/HTTPS 网页中的音视频播放器。默认启用不代表每个音源都可放大。
- 跨域媒体、DRM、网站权限或浏览器限制可能使处理受限；部分音源只能调低音量。以面板中对应网页的状态为准。
- Bilibili 在首次启用前保留网页原声，扩展不会写入播放器音量或静音。播放后点击工具栏扩展图标，面板自动尝试整页接管，音量与响度均衡随之生效，无需关闭自动模式。浏览器要求先唤起扩展才能接管受限网页；无法承诺对从未唤起扩展的所有标签页直接放大。原生播放器零音量和静音始终优先。
- 网页合成声音可直接使用「接管当前网页声音」，自动模式开启时也可使用。关闭自动模式不会停止已开启的整页接管，需另行停止。
- 浏览器内部页、扩展页和本地文件请使用原播放器调节。停止处理后，网页音量可能变化或变大；若声音未正常恢复，请刷新网页后重新播放。
- 峰值保护仅针对单个可处理音源的数字采样，不保证系统混音、重建峰值或耳边音量安全。受限音源的突发大声仍可能通过。

本地媒体与部分公开网页的验证不能代表所有视频网站、编解码器、跨域框架或播放方式。Windows、物理音频设备、长期运行与不同内容的主观听感仍需补充验证。

使用方式见 [使用指引](USAGE.md)。实际效果受音源、站点与浏览器限制。
